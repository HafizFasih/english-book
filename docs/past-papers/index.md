## Recurring Question Types

These question types appear consistently across all years:

- **Q1** — Reading Comprehension (passage + MCQs / True-False / short answers)
- **Q2** — Précis Writing with a suitable title
- **Q3** — Paragraph Writing (topic sentence given)
- **Q4** — Essay Writing (thesis statement + transitions)
- **Q5** — Formal Letter Writing (to Dean / Vice Chancellor)
- **Q6** — Report Writing (audit / event / informational)
