# Word Families

A **word family** is a group of words that share the same base or root and are related in meaning. Each member of the family has a different grammatical function — noun, verb, adjective, or adverb — created by adding prefixes or suffixes to the root.

Knowing one word in a family helps you understand and use the others without looking them up.

> **Example:** The root **act** gives us:
> - *action* (noun) — *The action was unexpected.*
> - *act* (verb) — *She acted quickly.*
> - *active* (adjective) — *He is an active member.*
> - *actively* (adverb) — *She actively participated.*

## How Word Families Are Formed

### By Adding Suffixes

Suffixes change the grammatical category of a word:

| Suffix | Creates | Example |
|--------|---------|---------|
| **-tion / -sion** | noun from verb | educate → *education* |
| **-ment** | noun from verb | develop → *development* |
| **-ness** | noun from adjective | dark → *darkness* |
| **-ity** | noun from adjective | possible → *possibility* |
| **-er / -or** | noun (agent) | teach → *teacher* |
| **-ful** | adjective from noun | beauty → *beautiful* |
| **-less** | adjective from noun | care → *careless* |
| **-ive** | adjective from verb | create → *creative* |
| **-al** | adjective from noun | environment → *environmental* |
| **-able / -ible** | adjective from verb | manage → *manageable* |
| **-ly** | adverb from adjective | careful → *carefully* |
| **-en** | verb from adjective | strong → *strengthen* |
| **-ify / -fy** | verb from noun/adjective | simple → *simplify* |
| **-ise / -ize** | verb from noun/adjective | organ → *organise* |
